# Requirements

| File | What it is |
|---|---|
| `SRS-v1.1.md` | The current SRS. Edit this file; changes are reviewed as pull requests. |
| `SRS-v1.1.pdf` | PDF copy of v1.1 for sharing. Regenerate it whenever the Markdown changes. |
| `SRS-v1.0.pdf` | The original SRS (17 July 2026), kept for reference. |

Requirement IDs never change once published. New requirements get new IDs; changed ones keep theirs
and are marked in the text. The decisions behind v1.1 are in `docs/adr/0007` and `docs/adr/0008`.
